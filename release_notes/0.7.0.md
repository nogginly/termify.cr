# `termify.cr`

## Release 0.7.0

### BREAKING

- `ANSI::SubScroller` is now `Termify::ScrollRegion`. It depends on `Terminal`, and `ANSI` sits below `Terminal` rather than above it, so the old namespace pointed the layering the wrong way round. The new name says what the class is: it owns one terminal scroll region. The old one named a comparison rather than a thing, and credited the class with scrolling, which the terminal does.
- `ScrollRegion.write_thinking_chunk` is gone. It printed a string and flushed; callers can do that themselves, to whichever `IO` they meant.

### IMPROVEMENTS

- `Terminal` takes the `IO` pair it talks to: `Terminal.new(input, output)`, defaulting to `STDIN` and `STDOUT`. `Terminal#output` is public, and `ScrollRegion` writes through it, so a region can no longer write to one place while asking another where the cursor is.
- `Terminal#interactive?` reports whether both ends are a terminal, which is the condition for asking it anything.
- `ANSI::Screen.scroll_region` and `.reset_scroll_region` join the other sequence helpers, and `ScrollRegion` now uses them along with `ANSI::Cursor` instead of building escapes by hand.
- `ScrollRegion` and `Terminal#cursor_row` now have specs, having previously had none: both needed a live terminal to run at all.

### FIXES

- `Terminal#with_raw_input` no longer changes the mode of the real terminal when its input is a pipe or a file, where there is no mode to change.
