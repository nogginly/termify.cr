# `termify.cr`

## Release 0.6.1

### FIXES

- Fix inline markup being stripped from table cells. Bold, italic, code spans and
  links now render inside tables.
- Fix table borders and headers losing their styling when output is not a
  terminal, such as when piped to a file.
- Fix ordinary prose being rendered as a table. A line is only treated as a table
  row when a delimiter row follows it, so text such as `if x || y` or a heading
  containing a pipe is left alone.
- Fix pipes inside code spans and pipes escaped as `\|` being treated as column
  separators rather than cell content.
- Fix a table immediately followed by a blockquote or heading being dropped
  instead of rendered.
- Fix table column widths being packed too narrowly, and a failed table render
  leaving later tables capped to the wrong width.
