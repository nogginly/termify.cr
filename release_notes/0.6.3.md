# `termify.cr`

## Release 0.6.3

### IMPROVEMENTS

- Report progress while the renderer holds content back. A table cannot be drawn until its last row arrives, and a highlighted code block until its last line, so a streaming caller sees output stop and cannot tell working from hung.
    - Pass `on_gather` to `Termify.render_markdown` or `Markdown::Renderer` to receive a `GatherEvent` when a block starts, progresses and finishes, carrying the kind of block for which rows are being gathered and a running count of rows or lines.
- Accept `3)` as well as `3.` for ordered lists. Both render as a full stop.
- Use `*`, `+` and `-` for unordered list bullets by depth, replacing the former asterisk, en dash and middle dot.
- Honour `line_prefix` on the `ListItem` style.
- `samples/md2term` now shows a progress indicator, and reads slowly enough to see it.

### FIXES

- Fix `Terminal#cursor_row` hanging forever when stdin or stdout is redirected.
- Fail at build time, not at program start, on a platform with no `Terminal` implementation.
- Fix a second blank line appearing between a list and whatever follows it.
- Fix the body of an unterminated code block being discarded.
- Fix a `Stylesheet` sharing its entries with the hash it was built from.
- Fix a plain `BlockStyle` assigned to `CodeBlock` losing its colours and prefixes.
